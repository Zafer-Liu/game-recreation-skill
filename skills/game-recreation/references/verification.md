# 验证与发布

## 运行边界与证据等级

继承用户与工程约定。分析、写文件、安装、运行工具、构建/测试、浏览器、提交、推送与部署不是同一授权。已有授权持续有效；受限时继续允许的工作并记录未运行，不把“复刻”改写为用户批准了全部命令。

用 `verification-report.md` 记录 **通过 / 失败 / 未运行 / 不适用**。每项绑定具体版本/种子、路径、操作、条件与结果。相应结论所需的证据不同：

| 证据 | 能证明什么 | 不能替代什么 |
| --- | --- | --- |
| 导入/编译/构建、字节/哈希核对 | 源码可解析、交付文件完整 | 画面质量、可玩性、离线 |
| 单模块仿真、桩或调试夹具 | 指定初始状态下的局部逻辑 | 普通玩家能达到该状态 |
| 干净开局的正常输入路线 | 声明控制方式下的可达性、循环和状态切换 | 未实际触发的分支、未测试的平台 |
| 同条件参考与实机画面/录屏对照 | 已展示的构图、轮廓、层次与节奏差异 | 未展示交互与未经测量的性能 |
| 最终生产包在独立文件/禁网/file 协议下运行 | 该版本和环境中的分发可用性 | 其他包或开发服务器的行为 |

## 正常路线是核心验收

从干净开局使用声明的普通输入走完：启动 → 发现目标/规则 → 执行核心动作 → 反馈与下一步决策 → 成功或失败 → 重开再操作。自动化可以使用真实键鼠/触屏事件，但以游戏真实状态确认结果，不能仅靠等几秒、DOM 存在或按钮点击成功判通过。

这条路线不使用传送、补资源、直接合并实体、修改任务标记或触发胜利事件。为定位问题允许这些调试夹具，但在报告另列“夹具验证”，不填入“正常路线通过”。发现只有靠夹具才能成功时，回头修可达性、输入/镜头、交互容差或教程。

检查获得核心道具与到达目标的成本是否被实际资源支持：路径/关卡可走，跳跃/滑翔/载具/消除等能力足够，碰撞与可见地形一致，触发提示出现的位置确实可操作。随机关卡还应说明验证了哪些种子，不能据单一种子证明全部布局有效。

## 最小验证矩阵

| 类别 | 操作 | 可接受结果 |
| --- | --- | --- |
| 首启 | 冷启动、标题→开始 | 遮罩实际消失、进入可操作状态，错误可见 |
| 取景与输入 | 转动/移动/点击核心对象 | 方向、尺度、指针与目标区域一致；目标可见可触发 |
| 核心循环 | 干净开局正常操作一轮 | 规则、资源、目标、反馈共同成立，无调试绕过 |
| 完成/失败 | 分别触发结果 | 结算正确，单次触发，可重开 |
| 重开 | 连续三次并再次执行核心动作 | 实体/监听/音频不叠加；输入、目标和资源复位 |
| 输入边界 | 按下、释放、失焦、暂停恢复 | 无粘键、暂停期间无额外动作、恢复后仍可控 |
| 音频 | 首次手势、静音、重开 | 可解锁、可停止、单次动作无重复播放；失败不阻塞玩法 |
| 视觉质量 | 同条件对照质量契约 | 逐项记录 G1 的目标与差异，不能用色板相似掩盖占位轮廓 |
| 生产包 | 核对 hash 后打开该包再走关键路线 | 已验收版本与实际交付版本对应 |
| 离线 | HTML 单独复制、禁网、file 协议 | 声明功能无网络或相邻文件依赖 |
| 体积 | 读取生产文件与报告 | 模式/哈希/原始/gzip 字节对应一致 |
| 平台 | 声明的输入、尺寸与浏览器 | UI 不遮挡关键对象，操作完整；未测平台明确 |

按项目适用性选择；没有音频、触屏或 3D 的项目不为填表额外开发系统。

## 浏览器环境诊断

发生画面不变、操作无效或计时异常时，先检查当前 URL/构建版本、控制台错误、焦点、页面与宿主可见性、rAF 帧进度和输入接收。DOM 显示隐藏属性、定时器继续走、截图不变，分别不足以定位为游戏卡死或工具缓存。恢复可见性或转到已获授权的独立浏览器后再重试，不根据猜测反复改游戏。

## 视觉与性能条件

对照相近机位/局面、时间、动作和尺寸，依次看构图/比例/轮廓、光色与层次、关键动作、材质与 UI。截图来自实际渲染，代码更改后重新取得对应证据；未执行时保留未运行，不生成伪造截图。

性能记录浏览器、设备/GPU、前台状态、尺寸/DPR、画质、场景和采样时长，区分冷启动生成时间、进入可玩时间与滚动帧时。隐藏窗格、软件 WebGL 或单张截图不支持设备帧率结论。rAF 计数不是 GPU 时间，降低分辨率后的结果也不能宣称原生分辨率性能。

## 交付与状态用词

README 只写实际功能与操作。保存源码、锁文件、许可、种子、质量契约和验证报告；最终报告绑定生产 HTML 的 SHA-256。源码或包变化后，原证据只对旧版本有效。

- **源码已编写 / 静态检查通过**：说明具体范围，不隐含执行成功。
- **机制原型 / 辨识度切片 / 高还原复刻**：按质量契约及实际证据命名。
- **已打包，未完成验收**：用户提前要求交付或缺运行授权时适用；照样给产物，明确失败和未运行项。
- **正常路线验证通过**：确有无绕过输入路径；附对应版本和结果。
- **离线/file 协议验证通过**：只有最终独立文件实测才可使用。
- **已发布**：真实远端可访问才给 URL；提交/推送/部署分别按授权执行。

不以 agent 自报完成、设计自评分、代码量、token 消耗或包体小来宣布质量优秀。优先报告当前体验、最影响使用的不足和实证，不用庆祝性评价盖过明显缺口。
